# 试衣终端 / Live Fitting 用户手册

适用于 V1.1–V1.2，提供中文、English、日本語。

[打开用户手册](https://wilburkong23.github.io/software-install-guide/)

- iPad、安卓终端与安卓平板的下载、安装和更新指引
- 软硬件规格及网络要求
- 按安卓与 iOS 分类的常见问题

中文应用名称为“试衣终端”，英文和日文应用名称为“Live Fitting”。模型统一称为 base、pro。安装渠道与版本以官方通知为准。

## 安装视频

中、英、日三语均提供安卓首次安装与老版本换装视频，可在安卓终端及安卓平板的对应章节播放和下载。成片为 1920×1080、无声、内嵌步骤字幕；六版最终视频存于 `assets/videos/20261109/`，校验值与时长见该目录的 `manifest.json`。
