# 轻链AI试衣终端用户手册

面向运营、现场实施和客户的静态用户手册，提供中文、日语、英语内容。当前目录对应 V1.1–V1.2。

## 本地预览

在本目录运行 `python3 -m http.server 8765`，浏览器打开 `http://localhost:8765`。无需安装依赖或构建，也可直接打开 `index.html`。

## 结构

- `index.html` 页面入口
- `styles.css` 响应式样式
- `app.js` 多语言内容与页面路由
- `assets/` 保留原格式的教程截图

采用 Hash 路由，资源使用相对路径，支持 GitHub Pages 的 `/software-install-guide/` 子路径。版本、语言、设备与操作场景可通过链接直接访问。
